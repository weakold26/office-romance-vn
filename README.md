# 퇴근 삼십 분 전

성수동 12층, IT 스타트업 「궤도」의 수습 마지막 주. 브라우저에서 바로 플레이하는 오피스 로맨스 비주얼 노벨입니다.

**플레이: https://weakold26.github.io/office-romance-vn/**

## 이야기

수습 3개월의 마지막 주, 금요일 오후에 계약 전환 심사 결과가 나온다.
같은 주에, 옆자리 입사 동기의 계약도 끝난다.

- **한서윤** — 프로덕트 팀장, 5년차. 겉으로는 철두철미하고 차갑지만, 실수한 사람을 조용히 덮어 주고 야근 끝에 캔커피를 건넨다. 그리고 이번 심사의 심사위원이다.
- **오하람** — 프로덕트 디자이너, 입사 동기. 매일 간식을 챙기고 엉뚱한 농담으로 분위기를 풀지만, 계단참에서 혼자 밤을 그린다.

선택지 14개, 엔딩 5종(해피 2 · 노멀 2 · 히든 1). 히든 엔딩은 두 사람의 진실을 모두 확인하고 호감도를 고르게 쌓아야 열립니다.

## 기능

- 배경 크로스페이드, 2인 동시 연출(화자가 아닌 쪽 딤 처리)
- 히로인 2인 호감도 게이지
- 세이브 3슬롯 + 자동 저장 (`localStorage`)
- 백로그, 자동 진행, 스킵, 엔딩 도감
- WebAudio API로 합성한 BGM·효과음 (외부 음원 파일 없음)
- 데스크톱·모바일 반응형, 숫자키로 선택지 선택
- `word-break: keep-all` 기반 한국어 조판

## 조작

| 키 | 동작 |
| --- | --- |
| 클릭 / Space / Enter / → | 진행 |
| 1 ~ 4 | 선택지 선택 |
| L | 백로그 |
| A | 자동 진행 |
| S | 스킵 |
| Esc | 창 닫기 |

## 구조

```
index.html            타이틀·무대·UI
css/style.css         스타일 (라이트 오피스 테마)
js/engine.js          노드 진행, 분기, 호감도, 세이브, 엔딩
js/audio.js           WebAudio 합성 BGM·효과음
src/data/scenario.json  시나리오 (빌드 산출물)
assets/img/           배경 4장, 스탠딩 8장 (WebP)
tools/                시나리오 DSL, 에셋 빌드, 검증 스크립트
```

시나리오를 고칠 때는 `tools/s0_prologue.py` … `tools/s5_final.py`를 수정하고,

```
python3 tools/scenario_build.py && python3 tools/simulate.py
```

를 실행합니다. `simulate.py`는 끊긴 링크·막다른 길·고아 노드·도달 불가 엔딩을 검사하고, 무작위·전략적 플레이 4,000회로 모든 엔딩 도달을 확인합니다.

## 에셋

배경과 스탠딩은 이미지 생성으로 제작했고, `tools/build_assets.py`가 스탠딩의 배경을 투명 처리한 뒤 두 캐릭터의 키를 1500px로 정규화해 WebP로 내보냅니다.
